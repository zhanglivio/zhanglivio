# 欧洲客户地图看板 · Europe CRM Map

一个纯前端的可交互地图看板，按 **欧洲 → 国家 → 大区 → 城市** 逐级下钻，
鼠标悬停弹出客户卡片（客户抬头 + 多少天未回购 + 欠款），点击城市查看全部客户明细。

## 怎么打开

直接用浏览器打开 `index.html` 即可（双击文件，或本地起个静态服务）。

```bash
# 任选其一
python3 -m http.server 8080      # 然后访问 http://localhost:8080
# 或者直接双击 index.html
```

> 地图边界数据从公共 CDN 加载（D3 / 欧洲与意大利 GeoJSON），所以**打开时需要联网**。
> 客户数据是本地的，不会上传到任何地方。

## 怎么操作

- **悬停**国家 / 大区 / 城市 → 弹出该范围内客户列表（抬头、未回购天数、欠款）。
- **点击**国家 → 缩放进入，其余区域虚化，显示该国大区。
- **点击**大区 → 进入，显示城市客户打点。
- **点击**城市圆点 → 右侧面板列出该城市全部客户明细。
- 左上角 **← 返回**，或点顶部**面包屑**任意层跳转。
- 鼠标滚轮缩放、拖拽平移。

颜色规则（绿/黄/红）：正常 / 关注 / 预警，可在 `js/data.js` 的 `THRESHOLDS` 调整。

## 怎么填客户数据

只改 **`js/data.js`** 一个文件。每个客户一条：

```js
{ company: "客户抬头",          // 公司名
  country: "IT",               // 国家 ISO2：IT 意, FR 法, DE 德, ES 西...
  region:  "Lombardia",        // 大区名（意大利大区名见 data.js 注释）
  city:    "Milano",           // 城市
  lat: 45.4642, lng: 9.1900,   // 城市经纬度（同城客户填同一坐标即可；不填则归到大区中心）
  daysSinceRepurchase: 47,     // 距上次回购的天数
  debt: 8600,                  // 欠款金额
  currency: "€",               // 货币符号（可省，默认 €）
  note: "重点跟进" },           // 备注（可选）
```

把你的真实客户资料按这个格式贴进 `CUSTOMERS` 数组、删掉示例即可。
现在里面放了米兰 3 个 + 罗马/那不勒斯各 1 个**占位**示例。

## 加别的国家的大区

目前内置了**意大利**的大区边界。要加别的国家（如法国大区），
在 `js/data.js` 的 `MAP_CONFIG.regionSources` 里按格式加一行大区 GeoJSON 源即可；
没有配置大区源的国家，点进去会直接在国家轮廓上按城市坐标打点，同样可用。
