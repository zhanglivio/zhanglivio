# 欧洲客户经营雷达 · Europe Coverage Radar

一张能让你**一眼看出经营机会**的欧洲地图：

- 🕳️ **哪里是空白** —— 没有客户的国家/大区/城市，被红色虚线标出 = **待开发市场**
- ❄️ **哪里客户变冷** —— 很久没联系的区域亮红 = **该去维护，别让客户流失**
- 💰 **哪里有欠款** —— 欠款集中的区域 = **该去催收**

按 **欧洲 → 国家 → 大区 → 城市** 逐级下钻，悬停弹客户卡片，点城市看明细。

## 三个视角（顶部切换）

| 视角 | 看什么 | 怎么用 |
|------|--------|--------|
| **客户密度** | 每个区域有多少客户；无客户=红虚线空白 | 找**空白市场**去开发 |
| **久未联系** | 区域内最久未联系的天数（绿→黄→红） | 找**变冷的客户**去维护 |
| **欠款** | 区域欠款合计 | 找**欠款大户**去催收 |

左侧「**洞察**」面板会随视角和层级实时给出排行榜（空白区 / 最久未联系 / 欠款最高），点条目直接跳到地图对应位置。

## 怎么打开

**本地（最简单）**：直接**双击 `index.html`** 即可。D3、地图边界、客户数据全部内联打包，
无需联网、无需起服务器。把整个文件夹拷到任意电脑都能用。

**在线版**：推送到 `claude/status-check-bhwrwt` 分支后，在仓库 Settings→Pages
开启（Deploy from a branch）即得到网址，手机/电脑都能打开。

> 数据是怎么内联的：`assets/*.geojson.js` 由 `tools/make_inline_assets.py` 生成，
> 把边界写成全局变量；`js/app.js` 优先读这些变量，读不到才回退 `fetch`。

## 怎么操作

- **悬停** 国家/大区/城市 → 客户列表（抬头、未联系天数、欠款），无客户会提示「待开发」。
- **点击** 国家 → 进入，其余虚化，显示大区。
- **点击** 大区 → 显示城市客户点。
- **点击** 城市圆点 → 右侧明细面板。
- 顶部**面包屑**跳转、左上 **← 返回**、滚轮缩放、拖拽平移。

## 怎么填客户数据

只改 **`js/data.js`** 一个文件。每个客户一条：

```js
{ company: "客户抬头",
  country: "IT",                 // 国家 ISO2：IT 意, FR 法, DE 德, ES 西...
  region:  "Lombardia",          // 大区名（意大利大区名见 data.js 注释）
  city:    "Milano",
  lat: 45.4642, lng: 9.1900,     // 城市经纬度（同城填同坐标；不填则归到大区中心）
  daysSinceContact: 40,          // ★ 距上次“联系”的天数 —— “久未联系”视角看这个
  daysSinceRepurchase: 47,       // 距上次回购的天数
  debt: 8600, currency: "€",
  note: "重点跟进" },
```

「空白」是自动算出来的：地图上所有欧洲国家/大区都会显示，**没出现在你数据里的就是空白**，无需手动维护。

阈值（绿/黄/红的界线）在 `data.js` 的 `THRESHOLDS` 调整。

## 大区支持

目前内置**意大利**大区边界。没配大区边界的国家（法/德/西等），点进去会直接按**城市坐标打点**，密度/冷热/欠款一样能看。要补某国大区边界，在 `data.js` 的 `MAP_CONFIG.regionSources` 加一行即可。
